# Aimee E. — Artist Portfolio

A three-page portfolio site for Aimee Elizondo. Built as Project 1 for bootcamp.

## Live Site

https://loremipsumiamyourfather.github.io/Artist-s-Site/

## Pages

- **Home** —  image and artist introduction
- **Gallery** — six paintings displayed in a responsive grid
- **Contact** — contact form with name, email, and message fields

## Built With

- HTML5
- CSS3 (custom stylesheet)
- Bootstrap 5 (grid system)
- Google Fonts (Playfair Display, Lato)
- Git and GitHub Pages

## Running Locally

1. Clone this repository: `git clone https://github.com/LoremIpsumIamyourFather/Artist-s-Site.git`
2. Open `index.html` in a browser, or use a local server (VS Code Live Server works well)
